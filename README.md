# Marcellus - Slack Bot

A Slack bot that lives in your channels and talks back with attitude.

## What it can do

- `@Marcellus <message>` — ask it anything, it'll respond in a sarcastic and slightly rude way (but not actually mean)
- `/marc-ping` — check bot latency
- `/marc-catfact` — get a random cat fact
- `/marc-joke` — get a random joke
- `/marc-help` — show all commands
- `/marc-clear` — Clears bot history
- `/marc-clear-dm` — Clears your DM with bot
- `/marc-weather` 

## Try it out

Add Marcellus to any channel with `/invite @Marcellus` and @ mention it with a message to get a response.
